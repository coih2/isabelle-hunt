# Isabelle Hunt

Personal product site: large pastel bubbles, a mouse-reactive background, and a PM-focused portfolio.

Live (after GitHub Pages is enabled): [https://coih2.github.io/isabelle-hunt/](https://coih2.github.io/isabelle-hunt/)

## Local

```bash
npm install
npm run dev
```

## GitHub Pages

1. Create a GitHub repo named `isabelle-hunt` under `coih2` (or update `vite.config.js` `base` if the repo name differs).
2. Push `main`.
3. In the repo: **Settings → Pages → Source: GitHub Actions**.

The workflow in `.github/workflows/pages.yml` builds and deploys on every push to `main`.
